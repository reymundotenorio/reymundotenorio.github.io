DepSaber

A local-first supply-chain radar for dependency manifests, package-manager configuration, GitHub Actions, and build artifacts.

Scope & implementation

  • Baseline and delta scans surface changes between dependency snapshots.
  • Signed feed verification and CI guardrails connect local checks with delivery workflows.
  • An interactive Go CLI and a Vite report viewer keep analysis local, without uploading project reports.
