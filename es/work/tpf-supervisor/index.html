Sistema TPF-Supervisor

Sistema de escritorio para operaciones TPF en Granada: lugares, horarios, turnos, personal, horas extras, ausencias, roles y cálculo de planillas.

Archivo del proyecto

Alcance e implementación

  • Desarrollado en Java con MySQL como gestor de base de datos.
  • Horarios, ausencias, generación de roles, cálculos de planilla y reportes.
  • Cálculos de nómina y reportes operativos con JasperReports.

Tecnologías

  • Java
  • MySQL
  • JasperReports
  • Desktop
