TimeWeaver

Un flujo que convierte actividad de GitHub y eventos del calendario en borradores de horas de trabajo y asiste con su ingreso en el navegador.

Aplicación privada

Alcance e implementación

  • n8n orquesta integraciones con GitHub, Google Calendar y Google Sheets.
  • Resúmenes asistidos por OpenAI normalizan la actividad en registros semanales.
  • Una capa de TypeScript y Playwright automatiza el ingreso repetitivo en formularios web.

Tecnologías

  • n8n
  • TypeScript
  • Playwright
  • OpenAI API
  • REST APIs
