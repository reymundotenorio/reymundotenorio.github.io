DuePulse

Una PWA de finanzas del hogar que reúne facturas, estados de cuenta, vencimientos y señales de pago en un flujo de revisión.

Aplicación privada

Alcance e implementación

  • Ingesta desde Gmail y extracción de estados de cuenta asistida por IA, con sugerencias revisadas antes de crear registros.
  • Compromisos recurrentes, separación de acceso por hogar, recordatorios y notificaciones push.
  • Aplicación bilingüe con Next.js, TypeScript, Supabase e integraciones de OpenAI.

Tecnologías

  • Next.js
  • TypeScript
  • Supabase
  • OpenAI API
  • PWA
