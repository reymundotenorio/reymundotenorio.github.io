DepSaber

Un radar local de cadena de suministro para dependencias, configuración de paquetes, GitHub Actions y artefactos de compilación.

Ver código↗

Alcance e implementación

  • Escaneos base y diferenciales para identificar cambios entre versiones de las dependencias.
  • Verificación de feeds firmados y controles de CI conectados con los flujos de entrega.
  • CLI interactiva en Go y visor de reportes con Vite para analizar resultados localmente, sin subirlos a un servicio.

Tecnologías

  • Go
  • CLI
  • GitHub Actions
  • Vite
  • Supply-chain security
